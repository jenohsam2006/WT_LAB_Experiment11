About Project

Educational Course Portal Architecture

Built strictly following Experiment No. 11: Database Integration in Node.js Application Using MongoDB.

Node.js & Express.js

Robust asynchronous server using Express middleware to handle JSON requests, static file routing, and RESTful API endpoints for the student portal.

Official MongoDB Driver

Uses the official mongodb driver package to connect directly to local MongoDB Community Server (mongodb://127.0.0.1:27017).

Full CRUD Lifecycle

Real-time execution of insertOne(), find({}).toArray(), updateOne() with $set, and deleteOne().

Professional Blue UI

Crisp, accessible blue and white visual design featuring responsive grid systems, interactive feedback modals, and dynamic data filtering.
